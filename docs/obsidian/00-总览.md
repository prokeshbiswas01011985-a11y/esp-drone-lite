# ESP-Drone Lite 文档库

ESP-Drone Lite 是基于 [espressif/esp-drone](https://github.com/espressif/esp-drone)（GPL-3.0）精简而来的**极简自稳定飞行固件**，目标芯片 ESP32-S2 + MPU6050，仅保留姿态自稳定链路（互补滤波 + PID + WiFi CRTP）。

> [!tip] 使用方式
> 用 Obsidian 直接打开本目录（`docs/obsidian`）作为 vault 即可，笔记之间通过双链互相关联。
