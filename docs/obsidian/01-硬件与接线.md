# 硬件与接线

本页给出 ESP-Drone Lite 的最小硬件方案：一块 ESP32-S2 开发板（或 ESP_Drone_v1_2 主板）+ MPU6050 + 4 路空心杯电机驱动。引脚默认值来自固件 `Kconfig`（机型 `TARGET_ESP32_S2_DRONE_V1_2`），可在 `idf.py menuconfig → ESPDrone Config` 中修改。

## 引脚表

| 信号 | GPIO | 接法 |
|---|---|---|
| I2C0 SDA | IO11 | MPU6050 SDA |
| I2C0 SCL | IO10 | MPU6050 SCL |
| MPU INT | IO12 | MPU6050 INT（数据就绪中断，上升沿） |
| M1 | IO5 | SI2302 栅极（经 10kΩ 电阻），驱动电机 1 |
| M2 | IO6 | SI2302 栅极（经 10kΩ 电阻），驱动电机 2 |
| M3 | IO3 | SI2302 栅极（经 10kΩ 电阻），驱动电机 3 |
| M4 | IO4 | SI2302 栅极（经 10kΩ 电阻），驱动电机 4 |
| LED 红/绿/蓝 | IO8 / IO9 / IO7 | 可选状态指示 |

> [!warning] 电机转向
> 电机 1/4 顺时针、2/3 逆时针（对角同向）。接线前对照 [[04-架构说明]] 中的 power distribution 轴向，装反会导致起飞即翻。

## 电机驱动电路（每路）

```
ESP32-S2 GPIO ──[10kΩ]──┬── SI2302 栅极 (G)
                        │
                      [10kΩ 下拉到 GND，可选，防上电误转]
SI2302 源极 (S) ── GND
SI2302 漏极 (D) ── 电机负极
电机正极 ── VBAT（3.7V 锂电池）
电机两端并联 1N5819（反向续流，阴极接 VBAT）
```

固件 PWM 由 LEDC 产生（见 `components/drivers/general/motors`），占空比即油门。

## 最小 BOM

| 名称 | 数量 | 备注 |
|---|---|---|
| ESP32-S2 开发板（或 ESP_Drone_v1_2 主板） | 1 | 需引出 IO3/4/5/6/10/11/12 |
| MPU6050 模块（GY-521） | 1 | I2C 地址 0x68 |
| SI2302（N 沟道 MOS） | 4 | 也可用 AO3400 等逻辑电平 MOS |
| 1N5819 肖特基二极管 | 4 | 续流保护 |
| 720 空心杯电机 | 4 | 两正转两反转 |
| 10kΩ 电阻 | 4~8 | 栅极限流（+可选下拉） |
| 3.7V 锂电池 | 1 | 单节，PH2.0 或焊线 |
| 机架 | 1 | 轴距约 85~100mm 的小四轴 |

> [!note] 电池电压
> Lite 版已移除 ADC 电压采样（见 [[05-裁剪记录]]），固件按标称 3.7V 上报电池电压，请自行留意飞行时间，勿过放。

## 打板方案（不想飞线的看这里）

上面的飞线方案适合**第一台原型**：零打板成本、改动灵活。验证没问题后，推荐改用正式 PCB——仓库自带官方主板的完整生产文件，无需自己画板。

### 官方主板文件（`hardware/ESP32_S2_Drone_V1_2/`）

| 文件 | 用途 |
|---|---|
| `src/Gerber_Mainboard_ESP32_S2_Drone_V1_2.zip` | 打板厂上传即用（嘉立创/JLCPCB） |
| `src/*.pcb`、`*.DSN` | Eagle 原始设计文件，想改板时导入（立创EDA专业版支持导入 Eagle） |
| `Bom/BOM*.xlsx`、`Placement/` | 元器件清单 + 贴片坐标，下 SMT 贴片订单用 |
| `Bom/Assemble*.pdf` | 官方装配说明 |

这块主板就是 lite 固件的目标机型 `ESP32_S2_DRONE_V1_2`：**ESP32-S2 + MPU6050 + 4 路电机驱动全部集成**，焊好元件后直接烧录固件即可，无需任何飞线（引脚对应关系与上方引脚表一致）。

### 下单流程（嘉立创为例）

1. 上传 Gerber zip → 默认参数打样（5 片，FR-4，1.6mm）
2. 元件二选一：
   - **自焊**：按 `BOM*.xlsx` 采购元件，对照 `Assemble*.pdf` 手工焊接（需要热风枪或加热台，贴片元件较多）
   - **SMT 贴片**：下单时选择"SMT 贴片"，上传 BOM + `Placement/` 坐标文件，工厂焊好发货（贵一些但省心）
3. 到手后跳到 [[03-编译与烧录]] 烧录固件

### 自己画 lite 简化板（进阶）

官方主板保留了 lite 已裁掉功能的外设位（光流板接口等）。想要更小的板子，可用立创EDA导入 Eagle 文件裁剪：只留 S2 最小系统 + MPU6050 + 4 路 MOSFET 驱动即可，引脚保持上方引脚表不变，固件无需改动。

> [!tip] 怎么选
> 第一次做 → 飞线原型（[[02-焊接步骤]]）验证固件；想长期玩/多台 → 直接打官方主板 + SMT 贴片。
