# 编译与烧录

固件基于 **ESP-IDF v5.0**，目标芯片 **esp32s2**。

## 1. 安装 ESP-IDF v5.0（建议装 D 盘）

```powershell
# 克隆（国内可换 gitee 镜像）
git clone -b release/v5.0 https://github.com/espressif/esp-idf.git D:\esp-idf

# 工具链全部落盘 D 盘，避免占用 C 盘
$env:IDF_TOOLS_PATH='D:\esp-idf-tools'
$env:IDF_GITHUB_ASSETS='dl.espressif.com/github_assets'
& D:\esp-idf\install.ps1 esp32s2
```

> [!tip] 子模块缺失
> 如果 `git clone` 没有带 `--recursive`，编译会报 mbedtls 目录不存在。可直接下载官方完整包：
> `https://github.com/espressif/esp-idf/releases/download/v5.0.8/esp-idf-v5.0.8.zip`（含全部子模块，解压即用）。

每次新开终端先激活环境：

```powershell
$env:IDF_TOOLS_PATH='D:\esp-idf-tools'
& D:\esp-idf\export.ps1
```

## 2. 编译

```powershell
cd esp-drone-lite
idf.py set-target esp32s2
idf.py build
```

产物：`build/ESPDroneLite.bin`。

> [!note] 低配置机器
> 编译占 CPU 较高，可加并行限制：`idf.py build -- -j2`。

## 3. 烧录与监视

```powershell
idf.py -p COMx flash monitor
```

`COMx` 换成设备管理器中 ESP32-S2 的串口号。串口看到 `MPU6050 I2C connection [OK].` 与 WiFi 启动日志即成功。

## 4. WiFi 连接与遥控

| 项目 | 值 |
|---|---|
| SSID | `ESP-DRONE-<MAC 后几位>`（由 `CONFIG_WIFI_BASE_SSID` 决定） |
| 密码 | `12345678`（`CONFIG_WIFI_PASSWORD`） |
| CRTP 协议 | UDP，端口 **2390** |

手机/电脑连上该热点后，用 cfclient（ESP-Drone 适配版，见上游 [espressif/esp-drone](https://github.com/espressif/esp-drone) README）或 ESP-Drone App 连接控制。Lite 版仅支持**姿态（自稳定）模式**：油门 + roll/pitch/yaw 角速率/角度，无定高与定点（见 [[05-裁剪记录]]）。

> [!warning] 解锁与急停
> cfclient 中解锁（arm）后才能给油门；通讯超时约 0.5s 固件自动切断电机，失联不会飞车。
