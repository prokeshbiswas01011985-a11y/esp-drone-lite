# 焊接步骤

按**焊点数从少到多**排序，每一步都有检查点，出错可以尽早发现。引脚编号见 [[01-硬件与接线]]。

> [!warning] 安全
> 全程**不要接电池**，焊接完成并检查通过后再上电。烙铁温度 320~360°C，飞线用 0.5mm 以下细漆包线或硅胶软线。

## 第一步：MPU6050 飞线（5 个焊点）

1. 在 GY-521 模块的 VCC / GND / SDA / SCL / INT 焊盘上各上一点锡。
2. 焊 5 根飞线（INT 也要接，固件依赖数据就绪中断）。

**检查点**：焊完先用万用表量 GND 与 VCC 之间通断，确认无短路。

## 第二步：开发板侧 I2C 接线（5 个焊点）

1. SDA → IO11，SCL → IO10，INT → IO12，VCC → 3V3，GND → GND。

**检查点**：上电（USB），先不装电机，按 [[03-编译与烧录]] 烧入固件后打开串口监视器，看到 `MPU6050 I2C connection [OK].` 即 I2C 焊接合格。失败则检查 SDA/SCL 是否接反、INT 是否虚焊。

## 第三步：栅极电阻（8 个焊点）

1. 4 只 SI2302 的栅极各串一只 10kΩ 电阻，电阻另一端焊到 IO5 / IO6 / IO3 / IO4。
2. （推荐）栅极到 GND 再各并一只 10kΩ 下拉电阻，防止上电瞬间电机误转。

**检查点**：量 GPIO 焊点到 MOS 栅极的阻值约 10kΩ。

## 第四步：MOS 与电机电源回路（约 16 个焊点）

1. 4 只 SI2302 源极接 GND、漏极接对应电机负极，电机正极接 VBAT。
2. 每个电机两端反并联 1N5819（阴极朝 VBAT）。
3. VBAT 与 GND 之间建议并一个 100~470µF 电容，减少电机纹波导致重启。

**检查点**：
- 万用表二极管档量每个电机两端，应看到二极管压降（约 0.2V，肖特基）；
- 量 VBAT 与 GND 之间无短路；
- 先**不装桨**，烧录固件后用 cfclient 逐个点动 M1~M4，确认转向正确（见 [[01-硬件与接线]] 的转向警告）。

## 第五步：装桨与首飞前检查

1. 确认四电机转向与桨的正反标记匹配。
2. 机架重心位于几何中心，MPU6050 安装方向与固件坐标一致（丝印 X 轴朝机头）。
3. 首飞在开阔处、低油门试姿态自稳，参考 [[04-架构说明]] 理解控制回路后再调 PID。
