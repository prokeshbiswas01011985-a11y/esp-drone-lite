# 裁剪记录

相对上游 espressif/esp-drone，本项目于 2026-08 完成物理裁剪，目标：**只保留自稳定飞行**。所有被修改文件均保留 GPL 版权头并追加修改标注。

## 删除清单

### 驱动组件层（Task 2）

- `components/drivers/deck` — deck 扩展板框架（光流板/TOF 板等全部依赖它）
- `components/drivers/spi_devices/pmw3901` — 光流传感器
- `components/drivers/i2c_devices/{hmc5883l,ms5611,vl53l1x,eeprom,vl53l0x}` — 磁罗盘、气压计、ToF、EEPROM
- `components/lib/dsp_lib` — CMSIS-DSP 移植库（改为用 `math.h` 直接实现，见下）
- adc、buzzer、eskylink 等驱动

### 核心模块（Task 4）

- **估计器**：`estimator_kalman.c` 及其 lighthouse/tdoa 定位源全部删除，只留互补滤波
- **控制器**：`controller_indi.c`、`controller_mellinger.c`、位置控制器
- **高层指令**：`crtp_localization_service.c`、高层 commander、航点 pptraj 相关
- **传感器扩展逻辑**：sitaw 坠落检测、lighthouse 目录整体删除
- `system.c` 中 adc/buzzer/sound/mem 服务注册删除

### HAL 层（Task 5）

- `sensors_mpu6050_hm5883L_ms5611.c` → 改名 `sensors_mpu6050.c`：删除磁罗盘/气压计/测距/光流分支；mag 填 0、baro 填常量，保留 LOG 组数据源
- `pm_esplane.c`：删除 ADC 电压采样与蜂鸣器提示，电压固定标称 3.7V
- 删除 21 个 HAL 源文件（buzzer、espnow_ctrl、radiolink、syslink、usb、其余传感器板实现等）
- `configblockeeprom.c` 重写为返回默认值的 stub（EEPROM 驱动已删）

### cf_math 重写（Task 3）

`cf_math.h` 不再依赖 dsp_lib：`xtensa_sqrt` 改为 `sqrtf`，矩阵 API 全部删除（仅互补滤波与 PID 使用标量运算）。

### 平台与配置（Task 6）

- 机型收敛为 `ESP32_S2_DRONE_V1_2` 单一目标（删除 ESPlane V1/V2_S2 配置）
- `Kconfig` 删除 buzzer menu、SPI 引脚、ADC 引脚、位置保持模式等配置
- 删除 `sdkconfig.defaults.esp32s3`；顶层工程改名 `ESPDroneLite`

## 体积对比

编译环境：ESP-IDF v5.0.8，目标 esp32s2（`IDF_TARGET=esp32s2`，与上游默认一致）。

| 指标 | 上游基线 | Lite 版 | 变化 |
|---|---|---|---|
| bin 大小 | 869600 B (0xD44E0) | 739200 B (0xB4780) | -15.0% |
| map 大小 | 8531348 B | 7818870 B | -8.4% |

> [!note] 为什么不到 30%
> 计划预期 "bin 缩减 ≥30%"，实测 -15%。原因：大量被裁掉的代码（光流、UWB/TDOA、Lighthouse、deck 驱动等）在上游 esp32s2 默认配置下**本来就不参与编译**（由 Kconfig/机型配置门控），裁剪它们只减少源码体积与维护面，不减 bin。真正进 bin 的被删部分（Kalman 估计器、INDI/Mellinger 控制器、dsp_lib 部分函数）合计约 130 KB。

## 验证方式

```powershell
Get-ChildItem components,main -Recurse -Include *.c,*.h,*.txt | Select-String -Pattern "kalman|lighthouse|tdoa|pmw3901|vl53l|hmc5883|ms5611|sitaw|indi|mellinger|pptraj"
```

预期：`components/` 与 `main/` 源码中无功能性命中（仅注释/文档说明）。
